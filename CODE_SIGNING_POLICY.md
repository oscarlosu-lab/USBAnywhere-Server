# Code Signing Policy — USBAnywhere Server

Free code signing is provided by [SignPath.io](https://signpath.io/), with certificates by [SignPath Foundation](https://signpath.org/) for official open-source releases, alongside `SHA256SUMS.txt` manifests.

## Verification
Users can verify every Windows and macOS binary against the `SHA256SUMS.txt` manifest attached to each [GitHub Release](https://github.com/oscarlosu-lab/USBAnywhere-Server/releases).
